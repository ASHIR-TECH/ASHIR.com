Mobile Remote Agent System

M.A.R.S

MARS turns your phone into a remote co-pilot for the AI agent running on your desktop. Scan one QR code and the pairing is done — then chat with the agent in plain language, watch CPU and RAM across every connected peer, and orchestrate file transfers across your fleet from the palm of your hand. The phone carries no heavy endpoint of its own: it stays a thin, secure remote, so the intelligence never leaves the machines you own.

M.A.R.S · Home Screen

01

One-Scan Pairing

Scan the desktop’s pairing QR and the app validates it, stores it in SecureStore, and auto-configures the Desktop Agent. No manual URL entry, ever.

02

Agent Chat

Ask the desktop agent anything in plain language. Tool calls render as step cards and file operations become transfer tiles — identically, whichever model answered.

03

Device Hub

A grid of every paired node with OS, status, live CPU and RAM bars, last check, and one-tap rename or remove.

04

Transfers

Watch incoming and outgoing jobs move from queued to negotiating to transferring, with byte counts, peer IDs, and status tone on every row.

05

Live Relay

A lightweight WebSocket with exponential-backoff reconnect keeps device state and chat replies flowing to the phone in real time.

06

Secure by Design

Sessions, pairing payloads, and agent tokens live behind hardware-backed encryption. The phone holds no P2P keys — the desktop enforces its own policy store.
