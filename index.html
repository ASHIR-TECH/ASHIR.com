The Problem

Every AI agent interaction involving files is broken.

Cloud dependency

Files must be uploaded through a browser and downloaded through a browser. Every file passes through third-party cloud servers.

No intelligence

Agents have no awareness of what they are receiving. Files arrive without schema, summary, or context.

No direct path

Two agents on different machines cannot communicate directly. There is no peer-to-peer file transfer protocol for AI agents.

How It Works

Install. Connect. Transfer.

01

Install

Run the ADTP peer daemon on any machine — laptop, EC2, or server.

02

Connect

Register with the rendezvous server and add trusted peers by peer ID.

03

Transfer

Tell your agent to send a file. It moves peer-to-peer over QUIC, encrypted end-to-end.
